These are the specs for `cNGN-USDC` spot and the `cNGN-30NOV26` future. The venue also lists
`EURC-USDC`, `EURC-30NOV26` and cNGN options. Read the live values for every market from
[`GET /v1/markets`](/api-reference/endpoint/get) rather than hard-coding them.

## Specs

| | `cNGN-USDC` | `cNGN-30NOV26` |
| --- | --- | --- |
| Type | Spot | Cash-settled dated future |
| Base / quote | cNGN / USDC | cNGN / USDC |
| Price unit | USDC per cNGN | USDC per cNGN |
| Size unit | 1 cNGN | 1,000 cNGN (0.001 contract) |
| Contract size | — | 1,000,000 cNGN |
| Minimum size | 1 unit | 1 unit |
| Size step | 1 unit | 1 unit |
| Tick size | 1e-18 | 1e-18 |
| Taker fee | 15 bps | 15 bps of notional |
| Maker fee | 0 | 0 |
| Margin | Fully funded | 25% initial, 15% maintenance |
| Settlement | Each fill, on chain | Cash, at expiry |

## Futures dates

| | Value |
| --- | --- |
| Expiry | 2026-11-30 14:00 UTC (`expiry_timestamp` 1796047200) |
| Last trade | 2026-11-30 13:00 UTC, one hour before expiry |
| Settlement price | Time-weighted average of the [index](/markets/index-price) over the last hour |
| Settled in | USDC, through [variation margin](/futures#variation-margin) |

A new series gets a new identifier, `<BASE>-<DDMONYY>`, and its own expiry.

<Note>
  `future.last_trade_time` is when the series stops trading. The top-level `last_trade_timestamp`
  on `GET /v1/markets` is something else: the time of the market's most recent fill.
</Note>

## Signing scales

| | `cNGN-USDC` | `cNGN-30NOV26` |
| --- | --- | --- |
| `amount_scale` | 1e18 (1 cNGN) | 1e15 (0.001 contract, 1,000 cNGN) |
| `limitPrice` | price × 1e18 | price × 1e18 |

See [Authentication and signing](/signing).

## Trading hours

Both markets trade around the clock. A future stops at its `last_trade_time`, and the matcher
pauses while the index is stale or the MarginEngine is paused.
