These are the specs for the `cNGN-30NOV26` future. The venue also lists `EURC-30NOV26`: see
[Futures](/futures) for its contract size, fee and margin. Read the live values for every market from
[`GET /markets`](/api-reference/endpoint/get) rather than hard-coding them.

## Specs

| | `cNGN-30NOV26` |
| --- | --- |
| Type | Cash-settled dated future |
| Base / quote | cNGN / USDC |
| Price unit | USDC per cNGN |
| Size unit | 1,000 cNGN (0.001 contract) |
| Contract size | 1,000,000 cNGN |
| Minimum size | 1 unit |
| Size step | 1 unit |
| Tick size | 1e-18 |
| Taker fee | 15 bps of notional |
| Maker fee | 0 |
| Margin | 25% initial, 15% maintenance |
| Settlement | Cash, at expiry |

## Futures dates

| | Value |
| --- | --- |
| Expiry | 2026-11-30 14:00 UTC (`expiry_timestamp` 1796047200) |
| Last trade | 2026-11-30 13:00 UTC, one hour before expiry |
| Settlement price | Time-weighted average of the [index](/markets/index-price) over the last hour |
| Settled in | USDC, through [variation margin](/futures#variation-margin) |

A new series gets a new identifier, `<BASE>-<DDMONYY>`, and its own expiry.

<Note>
  `future.last_trade_time` is when the series stops trading. The top-level `last_trade_timestamp`
  on `GET /markets` is something else: the time of the market's most recent fill.
</Note>

## Signing scales

| | `cNGN-30NOV26` |
| --- | --- |
| `amount_scale` | 1e15 (0.001 contract, 1,000 cNGN) |
| `limitPrice` | price × 1e18 |

See [Authentication and signing](/signing).

## Trading hours

Futures trade around the clock. A future stops at its `last_trade_time`, and the matcher
pauses while the index is stale or the MarginEngine is paused.
