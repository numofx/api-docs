---
title: 'Create a deposit'
openapi: 'POST /deposits'
---

Opens a trading account under the MarginEngine and funds it, or tops up an existing account, with one signed `Action`. The venue pays the gas. One account trades both `cNGN-USDC` spot and the cNGN [futures](/futures).

<Warning>
  **EIP-7702 wallets:** Matching treats an EOA with a 7702 delegation as a contract wallet. The deposit is refused with `OV_InvalidSignature` unless the delegate implements ERC-1271's `isValidSignature`. Use an undelegated EOA or an ERC-1271 wallet. The same applies to orders and withdrawals.
</Warning>

## Before your first deposit

From the wallet that will own the account, approve the `DepositModule` for at least the deposit amount:

```text
USDC.approve(0x6540f8d9Eb599b045C05E45cb6a5B1730a806658, amount)
cNGN.approve(0x6540f8d9Eb599b045C05E45cb6a5B1730a806658, amount)
```

USDC on Base is `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`. cNGN is `0x46C85152bFe9f96829aA94755D9f915F9B10EF5F`.

### Or sign a permit instead

USDC only. cNGN has no permit, and a cNGN deposit carrying one is refused with **400**.

Sign an EIP-2612 `Permit` with USDC's domain (`name` `USD Coin`, `version` `2`, chain `8453`), `spender` set to the `DepositModule`, a `value` of at least the deposit, and your current USDC `nonce`. Send it with the action:

```json
"permit": { "value": "1000000000", "deadline": "1789400600", "signature": "0x…" }
```

The permit is skipped if your allowance already covers the deposit. A permit USDC refuses returns **400**.

## Signing the action

Sign an [`Action`](/signing) against the `Matching` domain:

| Field | Value |
| --- | --- |
| `subaccountId` | `0` for a new account, or your account's id to top up |
| `nonce` | any unused `uint256`, per owner and module |
| `module` | `0x6540f8d9Eb599b045C05E45cb6a5B1730a806658` |
| `data` | `abi.encode(uint256 amount, address asset, address managerForNewAccount)` |
| `expiry` | unix seconds, at most one hour ahead |
| `owner` | your address, which pays and owns the account |
| `signer` | same as `owner` |

`asset` must be one of:

| Token | `asset` | Minimum |
| --- | --- | --- |
| USDC | `0xA74E49b4Ed7cb176bc02ef4D8a1A3240C9aD4272` (`quote_asset_address`) | 10 USDC |
| cNGN | `0x37c976bb5d4887a714ef19AF6B83e34fe2f37c98` (`asset_address` of `cNGN-USDC`) | 15,000 cNGN |

- `amount` uses the token's 6 decimals: `1000000000` is 1,000. `type(uint256).max` is refused.
- `managerForNewAccount` is the MarginEngine, `0x0705219a1594d5Fc5dC2573da4082cAf3e1B0950`. It is ignored on a top-up, so send the same address or zero.

cNGN counts toward margin at a 50% factor and shares one cap. A deposit over the cap returns **400** with the room left.

Send the fields as strings, with `data` as hex:

```json
{
  "action": {
    "subaccount_id": "0",
    "nonce": "7",
    "module": "0x6540f8d9Eb599b045C05E45cb6a5B1730a806658",
    "data": "0x000000000000000000000000000000000000000000000000000000003b9aca00000000000000000000000000a74e49b4ed7cb176bc02ef4d8a1a3240c9ad42720000000000000000000000000705219a1594d5fc5dc2573da4082caf3e1b0950",
    "expiry": "1789400600",
    "owner": "0xYourAddress",
    "signer": "0xYourAddress"
  },
  "signature": "0x…"
}
```

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid request, frozen wallet, spent nonce, not your account, too little balance or allowance, or over the cap. A simulation revert listed here also names `revert`. |
| `401` | The signature does not authorize the action. |
| `422` | The simulation reverted for another reason. `revert` names it. |
| `429` | One deposit in progress per owner, three requests a minute, six submitted an hour. The hourly limit sends `Retry-After`. |
| `502` | Outcome unknown. See [Checking a deposit](#checking-a-deposit). |
| `503` | Deposits are off or paused: the gas reserve or hourly budget ran out, or the issuer paused the token or froze a venue contract. Retry later. |

## The outcome

```json
{
  "action_hash": "0x1a818d05…",
  "status": "confirmed",
  "accepted": true,
  "tx_hash": "0x…",
  "receipt_status": "success",
  "block_number": "52386004",
  "subaccount_id": "27",
  "asset": "0xa74e49b4ed7cb176bc02ef4d8a1a3240c9ad4272",
  "asset_symbol": "USDC",
  "amount": "1000.000000",
  "amount_units": "1000000000",
  "credited_e18": "1000000000000000000000",
  "amount_usdc": "1000.000000",
  "credited_cash_e18": "1000000000000000000000"
}
```

Use `subaccount_id` on your orders. `amount_usdc` and `credited_cash_e18` appear on USDC deposits only. `permit_tx_hash` appears when a permit was used.

| `status` | Meaning |
| --- | --- |
| `pending` | Being submitted. Returned with **202**. |
| `submitted` | Broadcast, receipt not known yet. |
| `confirmed` | Mined successfully. |
| `reverted` | Mined and reverted. |
| `rejected` | Refused before sending. You may resubmit the same request. |
| `unknown` | The venue could not confirm submission. |

## Checking a deposit

Read the record with `GET /deposits/{action_hash}`. `action_hash` is the EIP-712 hash of your signed action.

<Warning>
  After a timeout or **502**, look up the deposit or resend the **same** signed request, which never submits twice. Do not sign a new one: a second signed deposit is a second deposit.
</Warning>
